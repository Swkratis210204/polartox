# Reproducing the Synthetic Benchmark

This directory contains the code used to generate the synthetic datasets and
run the synthetic benchmark experiments reported in the paper.

The notebooks are **research and reproducibility code**. They are not part of
the `polartox` package itself. The package provides the implementation of
Polarized Trees and the synthetic data-generation utilities, while the
notebooks provide the experimental workflow used for the paper.

---

## Overview

The experimental workflow consists of two notebooks:

1. `datasetdemo.ipynb`
   - generates the synthetic datasets;
   - explores their distributions;
   - computes descriptive statistics and nDFU;
   - visualizes the known ground-truth structure;
   - saves the generated datasets and ground truth.

2. `treesbenchmark.ipynb`
   - loads the datasets generated by the first notebook;
   - evaluates the Polarized Trees method over the benchmark configuration
     space;
   - selects the best configuration using the synthetic ground truth;
   - evaluates the selected configuration on an unseen synthetic corpus;
   - saves the benchmark, model-selection, and inference results.

The datasets are generated **once** and then reused across all benchmark
configurations. This ensures that differences between configurations are not
caused by repeatedly resampling the synthetic data.
